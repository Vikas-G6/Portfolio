# Vikas Gurav — The Build

Portfolio of Vikas Gurav, Java full-stack developer (Spring Boot, React, AWS), with a minimal game-inspired interface: quests for projects, a story arc for experience, and a stat sheet for skills.

## Stack
React, TypeScript, Vite, Tailwind, motion

## Run locally
npm install
npm run dev

## Content
All text and project data live in `src/data/portfolio.ts`. Replace the resume at `public/assets/Vikas_Gurav_Resume.pdf`.
